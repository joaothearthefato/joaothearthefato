## Oyama Hub

Plataforma web para praticantes de **Karatê Kyokushin** organizarem os treinos, estudarem Katas e Kihons e acompanharem a evolução por graduação. O nome homenageia Masutatsu Oyama, criador do estilo.

Foi feito em grupo (grupo A, durante o técnico) e eu pratico Kyokushin, então o problema era um que eu conhecia de perto.

**O que dá para ver no código**

- Login, cadastro e recuperação de senha por token.
- Módulo de proteção CSRF, usado no painel admin e na API dele.
- Área do aluno para registrar treinos.
- Painel de administração separado, com API própria.
- Banco MySQL com `schema.sql` e migrations incrementais.
- Smoke tests que checam sintaxe PHP/JS, arquivos críticos e ausência de credenciais no código.
- Documentação de arquitetura e de deploy em [`docs/`](https://github.com/joaothearthefato/Oyama-Hub/tree/main/docs).

**Feito com** HTML, CSS, JavaScript, PHP (procedural) e MySQL.

Se for olhar só uma coisa, comece pela [arquitetura](https://github.com/joaothearthefato/Oyama-Hub/blob/main/docs/architecture.md): ela mostra como o projeto está organizado e por quê.
