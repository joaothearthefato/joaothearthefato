## 🥋 Projeto Principal — Oyama Hub

O **Oyama Hub** é uma plataforma web voltada para praticantes de **Karatê Kyokushin**. O objetivo principal é ajudar na organização de treinos, consulta de Katas e Kihons, acompanhamento de graduação de faixas e diário de evolução pessoal.

É o meu projeto ativo de estudo e laboratório, onde aplico conceitos de arquitetura web, acessibilidade e segurança.

### Funcionalidades implementadas:
- **Autenticação e Segurança:** Sistema de login/cadastro com hashes de senha seguros e proteção contra CSRF.
- **Painel do Usuário:** Dashboard funcional para registrar treinos, anotações e visualizar progresso.
- **Módulo de Conteúdo:** Guia prático de Katas, Kihons e lógica de visualização do sistema de faixas.
- **Administração:** Painel administrativo interno para gestão de conteúdos e usuários.
- **Acessibilidade completa:** Ajuste dinâmico de fontes, modo alto contraste, opção de redução de animações, espaçamentos adaptados e integração com leitura por voz.
- **UX/UI:** Interface responsiva com alternância nativa de tema claro/escuro.

🔗 **[Acessar repositório do projeto no GitHub](https://github.com/joaothearthefato/Kyokushin-Karate)**

*(O nome "Oyama" é uma homenagem a Masutatsu Oyama, criador do estilo Kyokushin).*
