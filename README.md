## ⛩️ Projeto em destaque — Oyama Hub

Plataforma web criada para praticantes de **Karatê Kyokushin** organizarem treinos, estudarem Katas e Kihons, acompanharem graduações de faixa e registrarem sua evolução no dojo. É meu principal projeto de estudo e também funciona como portfólio — em constante evolução (e eu adoro isso).

- 🔐 Login, cadastro e sessão de usuários com proteção CSRF e senhas com hash
- 📊 Dashboard com registro de treinos, anotações e acompanhamento de progresso
- 🥋 Estudo de Katas, Kihons e sistema de faixas
- 🛠️ Painel administrativo próprio
- 🌓 Tema claro/escuro
- ♿ Painel de acessibilidade completo (tamanho de texto, alto contraste, redução de animações, espaçamento extra e leitura de conteúdo por voz)
- 🖥️ Landing page interativa, com explorador de faixas e menu responsivo

🔗 **[Ver repositório](https://github.com/joaothearthefato/Kyokushin-Karate)**

> 🎋 *Curiosidade: o nome "Oyama Hub" é uma homenagem a Masutatsu Oyama, fundador do Kyokushin Karatê.*
