## O que estou construindo

### Oyama Hub

Uma plataforma web experimental para praticantes de Karate Kyokushin organizarem treinos, estudarem Katas e Kihons e acompanharem sua evolução por graduação.

**O projeto reúne:**

- autenticação e gerenciamento de usuários;
- registro de treinos e anotações;
- acompanhamento de progresso;
- conteúdos sobre técnicas, Katas e graduações;
- painel administrativo;
- preocupação com acessibilidade, segurança e organização de código.
